# 🚀 Recompa 0.4.0

¡Llega la versión 0.4.0 con un rediseño visual completo, soporte para dispositivos de doble pantalla y una experiencia de navegación mucho más fluida!

## ✨ Novedades

- **Seis nuevos temas visuales:** Personaliza la biblioteca, los ajustes y las fichas con los estilos Clásico, Estanterías, Lista, Arcade, Mosaico o Vitrina (Ajustes → Estilo).
- **Soporte para segunda pantalla:** Optimizado para dispositivos como la AYN Thor. La pantalla secundaria mostrará detalles del port, galerías y la cola de descargas.
- **Fichas de juego unificadas:** Si un juego cuenta con varios ports, ahora se agrupan en una única página para elegir cuál instalar, manteniendo valoraciones independientes por port.
- **Ports con emulador embebido:** Nuevo soporte técnico para juegos que se distribuyen empaquetados con su propio emulador.
- **Control de descargas:** Posibilidad de pausar y reanudar descargas sin perder el progreso.
- **Galerías y descubrimientos:** Galería de imágenes ampliada en cada port y nueva sección con los ports añadidos recientemente al catálogo.
- **Experiencia de usuario:** Pantalla con las novedades de la versión tras actualizar y acceso directo a Ko-fi en Ajustes para apoyar el desarrollo.

## 🛠 Correcciones y Mejoras

- **Disponibilidad y resiliencia de red:** Si recompa.app sufre bloqueos de red (por ejemplo, restricciones de operadoras), el catálogo y las carátulas se cargan automáticamente desde GitHub u otras fuentes alternativas.
- **Gestión de instalaciones y firmas:** Reconocimiento de ports instalados en versiones anteriores de la app y resolución guiada de conflictos al actualizar APKs con firmas o versiones antiguas.
- **Valoraciones al instante:** Los informes de compatibilidad enviados se reflejan de inmediato en la ficha del port.
- **Estabilidad:** Corrección de errores menores y optimizaciones generales del sistema.
