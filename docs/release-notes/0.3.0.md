Recompa 0.3.0 adds languages, background downloads, port suggestions and a fix for the Play Protect warning.

## What's new

- **Languages.** Recompa now starts in English and also comes in Spanish, French, Portuguese and German. Pick one in Settings (on Android 13+ it also shows up as the app language in system settings). Port descriptions follow the language you choose when the catalog has a translation.
- **Downloads keep going in the background.** You can leave the app while ports download, verify and install. Progress shows as a notification, and when a download finishes in the background a notification takes you to the install prompt.
- **Suggest a port.** A new button in the library, and a link when a search finds nothing, let you send a GitHub repository for the catalog. Recompa checks it isn't listed yet first.
- **Rate ports without a GitHub account.** Compatibility reports and port suggestions are sent straight from the app. If sending fails, the GitHub form is one tap away.
- **Link ports you installed elsewhere.** On a port's page, "I already have it installed" links an app you installed outside Recompa. If it doesn't match the catalog's package or signature, Recompa warns you that it may not be the same app and won't update it.
- **See where a port comes from.** Each fork on the port page opens its GitHub repository, with mouse, touch or gamepad.
- **Recompa updates.** The update banner checks again when you come back to the app and every few hours, and the twice-daily update check also notifies you about new Recompa versions.

## Fixes

- **Play Protect warning.** Recompa no longer asks for permission to see every installed app (QUERY_ALL_PACKAGES), one of the reasons Play Protect flagged it. Ports are still detected. If you still see the warning, tap "More details" → "Install anyway"; the site's FAQ explains why.
- **Catalog on fresh installs.** The catalog now loads from https://recompa.app, which fixes new installs that showed an empty library.
- **Library filters.** Picking a platform filter scrolls it fully into view.

## Installing

Download `recompa.apk` below and install it over 0.2.0; your ports and settings stay. If you are on a nightly build, uninstall it first: nightlies are signed with a different key.
