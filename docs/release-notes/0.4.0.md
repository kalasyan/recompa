# 🚀 Recompa 0.4.0

Version 0.4.0 is here, with a complete visual redesign, support for dual-screen devices and a much smoother browsing experience!

## ✨ What's new

- **Six new visual themes:** Customize the library, settings and port pages with the Classic, Shelves, List, Arcade, Mosaic or Showcase styles (Settings → Style).
- **Second screen support:** Optimized for devices like the AYN Thor. The secondary screen shows port details, galleries and the download queue.
- **Unified game pages:** If a game has several ports, they are now grouped on a single page where you choose which one to install, with separate ratings for each port.
- **Ports with an embedded emulator:** New support for games distributed packaged with their own emulator.
- **Sort the library:** By original game name, recently added, recently updated or best rated. Change it with the Select button, the sort button at the top or in Settings.
- **Download control:** Pause and resume downloads without losing progress.
- **Galleries and discovery:** A larger image gallery on each port and a new section with the ports recently added to the catalog.
- **User experience:** A screen with the version's changes after updating, and a Ko-fi shortcut in Settings to support development.

## 🛠 Fixes and improvements

- **Network availability and resilience:** If recompa.app is blocked on your network (for example, by ISP restrictions), the catalog and covers load automatically from GitHub or other alternative sources.
- **Installs and signatures:** Ports installed with earlier versions of the app are recognized, and conflicts are resolved step by step when updating APKs with other signatures or older versions.
- **Instant ratings:** Compatibility reports you send show up right away on the port's page.
- **Stability:** Minor bug fixes and general optimizations.
