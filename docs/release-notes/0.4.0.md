Recompa 0.4.0 brings styles that change the whole layout, the second screen of dual-screen handhelds, and a choice of port when a game has several.

## What's new

- **Styles.** Six layouts for the library, the port pages and Settings: Classic, Shelves, List, Arcade, Mosaic and Showcase. Pick one in Settings → Style.
- **Second screen.** On dual-screen devices like the AYN Thor, the other screen shows the selected port's art, its details and the download queue. Turn it off in Settings.
- **Pick your port.** Games with more than one port now have a single page. Choose which one to install; ratings are counted for each port.
- **Pause and resume downloads.** A paused download carries on where it left off.
- **Recently added.** A section shows the ports added in the latest catalog update.
- **More images.** Each port page has a gallery of the game's images.
- **Embedded emulators.** A new port type for games packaged with their own emulator.
- **What's new.** This window: the first time Recompa opens after an update, it shows what changed, in your language. Open it again from Settings.
- **Support Recompa.** A Ko-fi link in Settings and the top bar.

## Fixes

- **Catalog when recompa.app is blocked.** If recompa.app doesn't answer (some Spanish ISPs block it during football matches), the catalog loads from GitHub, and covers fall back to other sources.
- **Ports installed before.** Ports installed with an earlier Recompa are recognised again if their records were lost.
- **Install anyway.** When a download doesn't match the catalog, you can install it anyway after a warning. When Android can't update a port (another signature or an older build), Recompa offers to uninstall it and install the new one.
- **Ratings show up at once.** A compatibility report you send appears on the port page right away.
