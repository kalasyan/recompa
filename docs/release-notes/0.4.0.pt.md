O Recompa 0.4.0 traz estilos que mudam todo o layout, a segunda tela dos portáteis com duas telas e a escolha do port quando um jogo tem vários.

## Novidades

- **Estilos.** Seis layouts para a biblioteca, as páginas dos ports e as configurações: Clássico, Prateleiras, Lista, Arcade, Mosaico e Vitrine. Escolha um em Configurações → Estilo.
- **Segunda tela.** Em aparelhos com duas telas, como o AYN Thor, a outra tela mostra as imagens do port selecionado, os detalhes e a fila de downloads. Dá para desativar nas configurações.
- **Escolha seu port.** Jogos com mais de um port agora têm uma única página. Escolha qual instalar; as avaliações são contadas para cada port.
- **Pausar e retomar downloads.** Um download pausado continua de onde parou.
- **Adicionados recentemente.** Uma seção mostra os ports adicionados na última atualização do catálogo.
- **Mais imagens.** Cada página de port tem uma galeria de imagens do jogo.
- **Emuladores embutidos.** Um novo tipo de port para jogos que vêm com o próprio emulador.
- **Novidades.** Esta janela: na primeira vez que o Recompa abre depois de uma atualização, ela mostra o que mudou, no seu idioma. Você pode abri-la de novo nas configurações.
- **Apoie o Recompa.** Um link do Ko-fi nas configurações e na barra superior.

## Correções

- **Catálogo quando o recompa.app está bloqueado.** Se o recompa.app não responder (algumas operadoras espanholas o bloqueiam durante jogos de futebol), o catálogo é carregado do GitHub e as capas vêm de outras fontes.
- **Ports instalados antes.** Ports instalados com uma versão anterior do Recompa voltam a ser reconhecidos mesmo que os registros tenham se perdido.
- **Instalar mesmo assim.** Se um download não corresponder ao catálogo, você pode instalá-lo mesmo assim depois de um aviso. Se o Android não conseguir atualizar um port (outra assinatura ou uma build mais antiga), o Recompa oferece desinstalá-lo e instalar o novo.
- **Avaliações na hora.** O relatório de compatibilidade que você envia aparece na hora na página do port.
