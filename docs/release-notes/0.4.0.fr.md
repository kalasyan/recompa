Recompa 0.4.0 apporte des styles qui changent toute la mise en page, le second écran des consoles à double écran et le choix du port quand un jeu en a plusieurs.

## Nouveautés

- **Styles.** Six mises en page pour la bibliothèque, les pages des ports et les paramètres : Classique, Étagères, Liste, Arcade, Mosaïque et Vitrine. Choisissez-en un dans Paramètres → Style.
- **Second écran.** Sur les appareils à double écran comme l'AYN Thor, l'autre écran affiche les images du port sélectionné, ses détails et la file de téléchargements. Vous pouvez le désactiver dans les paramètres.
- **Choisissez votre port.** Les jeux qui ont plusieurs ports n'ont plus qu'une seule page. Choisissez celui à installer ; les évaluations sont comptées pour chaque port.
- **Mettre en pause et reprendre les téléchargements.** Un téléchargement en pause reprend là où il s'était arrêté.
- **Ajoutés récemment.** Une section montre les ports ajoutés lors de la dernière mise à jour du catalogue.
- **Plus d'images.** Chaque page de port a une galerie d'images du jeu.
- **Émulateurs intégrés.** Un nouveau type de port pour les jeux fournis avec leur propre émulateur.
- **Nouveautés.** Cette fenêtre : la première fois que Recompa s'ouvre après une mise à jour, elle montre ce qui a changé, dans votre langue. Vous pouvez la rouvrir depuis les paramètres.
- **Soutenir Recompa.** Un lien Ko-fi dans les paramètres et la barre du haut.

## Corrections

- **Catalogue quand recompa.app est bloqué.** Si recompa.app ne répond pas (certains opérateurs espagnols le bloquent pendant les matchs de football), le catalogue se charge depuis GitHub et les jaquettes viennent d'autres sources.
- **Ports installés auparavant.** Les ports installés avec une version précédente de Recompa sont de nouveau reconnus, même si leurs enregistrements ont été perdus.
- **Installer quand même.** Si un téléchargement ne correspond pas au catalogue, vous pouvez l'installer quand même après un avertissement. Si Android ne peut pas mettre à jour un port (autre signature ou version plus ancienne), Recompa propose de le désinstaller et d'installer le nouveau.
- **Évaluations immédiates.** Le rapport de compatibilité que vous envoyez apparaît tout de suite sur la page du port.
